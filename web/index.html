      Showcase sites are recorded runs. Any US address is screened against federal rules and a 1,291-entry moratorium dataset; state and grid rules: Texas/ERCOT; county sources (ordinance drafts, press releases, news): Washington Co. MD, Pima Co. AZ.

      How SiteWhy works

      AI reads and writes; code verifies and computes.

      What you get

      1. Verdict Go, conditional or no-go for this site at this load.
      2. The deciding rule Quoted word for word from its source, with the link.
      3. The math The threshold check, computed by code. e.g. 1,067 tpy ≥ 100 tpy
      4. What would change it The flips: the change that moves the verdict. e.g. at 25 MW instead of 300 MW → go

      Where AI is used Round 2

      1. 1 Planner AI · Nemotron Ultra Plans what to check.
      2. 2 County investigator AI · Nemotron Lightning Reads county sources and pulls out rules with quotes.
      3. 3 Evidence verifier Code · Python Checks every quote word for word against the source.
      4. 4 Rule check Code · Python Does the threshold and date math.
      5. 5 Adjudicator AI · Nemotron Ultra Writes the verdict and why-chain.
      6. 6 Critic AI · Nemotron Ultra Challenges it and can send work back for a second round.
